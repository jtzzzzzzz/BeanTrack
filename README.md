# BeanTrack ☕️

> Inventory management and operations dashboard for a coffee shop.

BeanTrack is a data-driven inventory management project designed to organize, monitor, and visualize the operational information of a coffee shop.

The project combines **MySQL and Excel** to transform structured inventory data into an interactive dashboard that makes key information easier to understand and supports day-to-day decision-making.

## ✦ Overview

Managing inventory involves more than simply knowing how many products are available.

BeanTrack was created to bring together product information, stock levels, categories, and expiration dates in a structured workflow, connecting database management with visual analysis.

The project is organized into three main components:

**Data → SQL → Dashboard**

Raw data is structured and managed through MySQL, processed through SQL scripts, and then presented through an Excel dashboard designed for quick analysis.

## ✦ Features

* Inventory organization by product and category
* Stock level monitoring
* Product expiration tracking
* Visual alerts for inventory requiring attention
* KPI indicators for quick analysis
* Interactive Excel dashboard
* Structured SQL database scripts
* Separation between raw data, database scripts, and visualization
